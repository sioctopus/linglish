# Linglish 界面规范

对照来源：https://www.speak.com/tw ，2026-10-15 从页面上量到的实际样式。
这套规范管营销页和产品页在宽屏上的外观。文案、链接、登录和上课入口保持原样。
安卓、iPhone、iPad 的尺寸和导航见 `ui-spec-mobile.md`；练习页的「完整又简洁」见 `ui-spec-mobile-practice.md`；顶栏/侧栏/底栏壳层（参照 YouTube）见 `ui-spec-shell.md`。颜色、字体、图标各份规范共用。

Axiforma 是 Speak 的商用字体，不能直接嵌进 Linglish。界面用 Manrope，中文回落到苹方、微软雅黑。

## 一句话

布局可以保持现在的留白和胶囊导航。颜色用 Linglish 官网自己的青绿，不要用 Speak 的蓝。

## 颜色

色值以 https://www.linglish.org 和 `tokens.css` 为准。

| 角色 | 色值 | 用在哪 |
| --- | --- | --- |
| 页面底 | `#f8fafc` | 默认页面底 |
| 卡片白 | `#ffffff` | 导航、白卡片 |
| 标题 | `#0f172a` | 标题和正文 |
| 说明 | `#64748b` | 标题下的说明 |
| 主色 | `#0f766e` / `#0d9488` | 品牌、强调、推荐边框 |
| 薄荷 | `#2dd4bf` | 主按钮渐变的亮端 |
| 天蓝 | `#0ea5e9` | 链接和信息，不是主按钮 |
| 按钮 | `#0d9488` → `#2dd4bf` | 主按钮，白字 |
| 浅底 | `#f0fdfa` / `#ccfbf1` | 推荐卡、功能浅底 |

状态色只用于对错和警告：成功绿、警告黄、错误红。不要拿来做大面积装饰。

## 文字

| 层级 | 字号 | 字重 | 行高 | 字距 | 颜色 |
| --- | --- | --- | --- | --- | --- |
| 营销大标题 | 64px | 400 | 70px | -0.13em | `#0f172a` |
| 区块标题 | 40px | 600 | 44px | -0.02em | `#0f172a` |
| 产品页标题 | 32px | 600 | 40px | 正常 | `#0f172a` |
| 卡片说明 | 20px | 400 | 30px | 略紧 | `#0f172a` |
| 副文案 | 16px | 400 | 24px | 正常 | `#64748b` |
| 界面字 | 14px | 500 | 20px | 正常 | `#0f172a` |

副文案最大宽度大约 480px，居中段落的文字容器大约 640px。
营销大标题可以在中文之间加少量空格，这是 Speak 首页的排版手法。产品页标题不要拆字。

## 形状和间距

| 零件 | 做法 |
| --- | --- |
| 导航 | 白底胶囊，高 68px，内边距 6px 16px，圆角全圆。贴在页面顶部，左右留出空隙 |
| 主按钮 | 青绿到薄荷渐变，白字，圆角全圆。导航里高约 46px，首屏主按钮高约 55px |
| 次按钮 | 白底、近黑字、细边框。不能和主按钮一样蓝 |
| 白卡片 | 白底，圆角 24px，阴影只用 `0 4px 90px rgba(0,0,0,0.04)` |
| 功能大块 | 浅青底 `#f0fdfa`，圆角 40px，内边距 56px |
| 问答容器 | 底 `#f8f8f8`，圆角 32px |
| 营销段间距 | 上下约 160px，白段和灰段交替 |
| 产品页间距 | 上下 48–80px。方案、今天、练习不要用营销页那么空 |
| 内容宽度 | 文案 640px，主栏 940px，大图区域最多 1216px |
| 专注模式边距 | 全屏专注时四周统一内边距 `--lx-focus-inset: 24px`；主栏与字幕栏间距 `--lx-focus-gap: 16px`。视频学习 / AI 陪练 / 实战场共用，不要贴边 |
| 专注播放窗口 | 三板块同一尺寸：`--lx-focus-player-max-h: min(68dvh, 680px, calc(100dvh - 210px))`，宽度 `--lx-focus-player-width`（16:9，居中）。控制条与播放窗同宽。非专注仍用 `60dvh/620px` |

## 页面怎么排

1. 顶上一条白色胶囊导航。左边品牌，中间少量链接，右边只有一颗青绿主按钮。
2. 首屏：深色大标题、灰色一句说明、一颗青绿到薄荷的渐变按钮。旁边可以放吉祥物或产品图。
3. 往下用白和 `#f8fafc` 交替分段。每段一个标题，一段说明。
4. 功能浅底用 `#f0fdfa` 和 `#ccfbf1`。
5. 价格、表单、推荐结果用白卡片。价格数字用 `#0f172a`。浅底上禁止白字。
6. 深色只留给视频演示条这类「屏幕里的画面」。整页、页脚、推荐卡片不要做成深色。

## 图标

全站 UI 图标统一用描边 SVG，不要混用 emoji、▶ 字符和各页手写 path。

| 规则 | 做法 |
| --- | --- |
| 来源 | `js/icons.js`（`LxIcon.html('play')`）或 `<span data-lx-icon="home"></span>` |
| 样式 | `styles/icons.css` + `tokens.css` 里的 `--lx-icon-*` |
| 画布 | 24×24，描边宽 `--lx-icon-stroke: 2`，圆角端点 |
| 颜色 | `currentColor`，跟父级文字/按钮色走 |
| 尺寸 | xs 14 / sm 16 / md 20 / lg 24 / xl 28 |
| 导航 | 桌面胶囊、移动底栏用 SVG；庆祝/成就可保留 emoji |
| 品牌标 | Google、微信登录图标单独保留，不算系统图标 |

新增图标先补进 `icons.js`，再在页面引用；不要在单页再贴一份 path。

## 不要做

- 不要把主按钮改成纯蓝，不要 3D 厚边按钮。
- 不要一屏放两颗同样抢眼的主按钮。次要动作用白底按钮或文字链接。
- 不要白字放在白底、浅灰底、浅青底上。
- 不要给每种功能分配一种颜色。
- 不要在产品控件上继续用 emoji 或 `▶` 当图标；统一走 `LxIcon`。

改页面时颜色以 `tokens.css` 为准。图标以 `icons.js` 为准。
