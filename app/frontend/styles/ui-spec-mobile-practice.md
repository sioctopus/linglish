# Linglish 手机练习页规范

颜色、字体、断点、安全区、触控下限仍以 `ui-spec-mobile.md` 为准。  
这一份只解决一件事：**功能可以齐全，但同一时刻屏幕上只能看到该看见的。**

适用：日常用语、850 句、跟读、精读入口、实景五段等「听 / 说 / 练」页。  
不适用：营销首页、定价页（仍走 `ui-spec.md` / `ui-spec-mobile.md`）。

---

## 一句话

手机练习页不是把桌面控件缩小塞进一屏。  
**完整 = 能力都能到达；简洁 = 当前任务只露出一层。**  
首屏只服务「这一句怎么练」，其余进二级入口。

---

## 完整 ≠ 全露

| | 错误做法 | 正确做法 |
| --- | --- | --- |
| 功能 | 每个能力都占一颗按钮 | 每个能力都有入口，多数藏在「更多」或模式里 |
| 信息 | 音标、词性、中文同时铺满 | 默认只显示练法需要的一层，点词再展开 |
| 导航 | 顶栏塞满包名、教材、返回 | 顶栏只留返回 + 页名；换包进抽屉 |
| 主操作 | 播放、跟读、精读同级并排 | 一屏一颗主按钮；次要描边；再低进溢出菜单 |

验收口诀：**首屏可点控件 ≤ 7；主按钮 = 1；同级切块 ≤ 3。**

---

## 五层结构（从上到下）

手机竖屏练习页固定成五层。缺层可以，多一层就要解释为什么。

```
┌─────────────────────────────────┐
│ 1 顶栏：返回 · 场景名 · 更多     │  高 56px + 安全区
├─────────────────────────────────┤
│ 2 情境条：场景标题 + 一句说明     │  最多两行；口音切到右上或更多里
├─────────────────────────────────┤
│ 3 练法条：最多 3 个分段          │  横滑可以，但不能换行成两排
├─────────────────────────────────┤
│ 4 舞台：当前句（唯一视觉重心）     │  占可视高度的大头
├─────────────────────────────────┤
│ 5 操作条：主操作 + 上一句/下一句   │  贴底；安全区；次要进「⋯」
└─────────────────────────────────┘
```

- **第 1 层**管去哪，不管怎么练。  
- **第 2 层**回答「现在练什么情境」。  
- **第 3 层**回答「用哪种练法」。  
- **第 4 层**只放当前句与跟读反馈。  
- **第 5 层**只放「这一刻最该按的」。

场景列表、整段对话、词表、精读、带走三句、听我的录音：**不进首屏常驻区**，用底栏 Tab、抽屉或「更多」到达。

---

## 控件配额

同一可视屏内：

| 类型 | 上限 | 说明 |
| --- | --- | --- |
| 主按钮 | 1 | 青绿渐变。播放页 =「播放」；跟读态可临时换成「说话中 / 松手结束」 |
| 次按钮 | ≤ 3 | 白底描边。典型：上一句、下一句、跟读 |
| 分段 / Tab | ≤ 3 | 如「先听再跟 / 先说再看 / 实景」；第 4 个起进更多 |
| 开关 | ≤ 2 | 如「纯字幕 / 翻译」；可收成图标或下拉 |
| 溢出入口 | 1 | 「更多」或 `⋯`，收纳朗读整段、本句精读、整段精读、带走三句、听录音、换口音等 |
| 悬浮专用钮 | ≤ 1 | 如舞台内麦克风；不要再叠第二颗悬浮 |

超过配额时：合并、降级进「更多」，或按练法切换显示，不要加高一排按钮。

---

## 操作分级

```
L0 主操作   → 渐变主按钮，宽可占满操作条左 1 或整行最上
L1 巡航     → 上一句 / 下一句（描边）
L2 本句辅助 → 跟读（描边或舞台内麦）
L3 场景工具 → 朗读整段、精读、带走、听录音 → 「更多」菜单
L4 全局设置 → 美式/英式、教材、切包 → 顶栏「更多」或情境条角标
```

规则：

1. L0 与 L3 不能并排成同一视觉重量。  
2. L3 用列表菜单（底滑 24px 顶圆角），每项一行 48px，不要再做成一排小胶囊。  
3. 录音中禁止切口音、切场景；用状态文案说明，不要静默失败。

---

## 信息分层（字幕 / 注解）

当前句是舞台中心。注解按需出现，不要默认「音标 + 词性 + 中文」三层全开。

| 层 | 默认 | 何时出现 |
| --- | --- | --- |
| 英文句 | 开 | 始终（「先说再看」未揭晓时用遮罩，不算关英文） |
| 中文整句 | 关 | 「翻译」开，或点句旁翻译 |
| 词级音标 | 关 | 点词展开；或「注音」开 |
| 词级词性 / 词义 | 关 | 点词展开气泡；不要每个词底下常驻两行灰字 |
| 说话人 | 开 | 一行小标签即可 |

「纯字幕」= 只留英文（+ 可选整句中文），关掉词级装饰与多余开关说明。  
舞台内可点热区仍 ≥ 44px；展开的词气泡点空白关闭。

---

## 练法切换

分段控件只切换**练法**，不要把「实景五段」「我的教材」和练法混成四个同级 Tab。

| 放进练法条 | 放进顶栏 / 更多 |
| --- | --- |
| 先听再跟 | 日常用语 / 850 句 / 教材（换内容包） |
| 先说再看 | 实景五段（换内容形态，用列表或二级页） |
| （预留第三） | 美式 / 英式 |

切练法时：一句灰色 `method-hint` 最多一行，可在首次进入该练法时显示 3 秒后淡出，不要长期占高。

---

## 顶栏（练习页专用）

不要用桌面浮动胶囊塞「Linglish + 日常用语 + 850句 + 我的教材 + 返回 + 首页」。

手机练习顶栏：

| 位置 | 内容 |
| --- | --- |
| 左 | 返回（48×48 热区） |
| 中 | 当前包或场景短名，单行截断 |
| 右 | 「更多」一个入口 |

换包、教材、首页、口音：进「更多」菜单。  
品牌名不必每页占一行。

---

## 情境条

```
路上见面                    [美式|英式]
见面 · 两个朋友在街上碰到
```

- 标题 22px / 字重 700；说明 14px / `#64748b`。  
- 说明最多两行，超出省略。  
- 口音切换用滑动分段（见日常用语现有样式），高度手机 ≥ 44px。  
- 窄屏（≤375）若放不下：标题独占一行，口音进「更多」并在说明旁显示当前「美式」文字状态。

---

## 操作条布局

推荐两种，二选一，整产品统一：

### A. 三键巡航（默认）

```
[  播放（主）  ]
[ 上一句 ] [ 下一句 ] [ 跟读 ]
[ 更多 · 朗读整段 / 精读 / … ]
```

### B. 主操作 + 麦在舞台

```
舞台内：大圆麦克风（跟读）
底部：[ 播放 ] [ 上一句 ] [ 下一句 ]
更多：其余
```

禁止：主按钮与四颗以上描边钮排成 2×2 或 2×3 网格抢视线。  
禁止：底部再挂一排等宽小胶囊（朗读整段 / 本句精读 / 整段精读 / 带走三句）。

## 对照：当前日常用语页 → 目标

以手机截图里的拥挤为首要反例。改版时按表收敛，功能保留。

| 现况（问题） | 规范目标 |
| --- | --- |
| 顶栏：Linglish + 四五个胶囊 | 返回 + 标题 + 更多 |
| 练法 3 Tab + 两个开关 + 常驻说明 | 3 Tab；开关收进图标或更多；说明可淡出 |
| 词上音标、词下词性+中文全开 | 默认英文；点词展开；翻译/注音按需 |
| 播放 + 上一句 + 下一句 + 跟读同栅格 | 1 主 + ≤3 次 |
| 底部四颗工具胶囊常驻 | 全部进「更多」底滑菜单 |
| 场景列表、对话栏与舞台抢首屏 | 列表用左滑抽屉或底部「目录」Tab |

功能完整性检查清单（改完仍须能做到）：

- [ ] 切美式 / 英式  
- [ ] 切先听再跟 / 先说再看  
- [ ] 进实景五段、日常、850、教材  
- [ ] 播放 / 暂停、上一句、下一句  
- [ ] 跟读、听自己的录音  
- [ ] 朗读整段  
- [ ] 本句精读、整段精读  
- [ ] 带走三句  
- [ ] 纯字幕、翻译（或等价信息层）  

以上全部可达，且首屏可点 ≤ 7、主按钮 = 1，即视为「完整且简洁」。

## 动效与反馈（克制）

| 场景 | 做法 |
| --- | --- |
| 分段、口音 | 滑块 200–240ms，ease-out |
| 按钮按下 | `scale(0.97)` 或浅底，≤ 120ms |
| 切句 | 舞台内容可轻微淡入，不要整页闪白 |
| 录音中 | 麦按钮脉冲或主色描边；其他危险切换禁用 |

不要：大面积渐变动画、每个词弹跳、多处阴影发光。

---

## 平板

- **竖屏**：仍用五层；内容宽 ≤ 720px 居中；操作条可略增左右内边距。  
- **横屏**：允许左目录 + 右舞台双栏；主按钮规则不变；不要把桌面三栏（目录 / 舞台 / 对话）原样压进手机逻辑。

---

## 视口：不横滑、不撑破屏

手机练习页整页禁止横向滚动。竖向可以滚，左右不能拖出空白。

| 规则 | 做法 |
| --- | --- |
| 根节点 | `html, body { max-width: 100%; overflow-x: hidden; overscroll-behavior-x: none; }` |
| 主栏 | `main` / `.workspace` / `.card` / `.stage` 一律 `max-width: 100%; min-width: 0; box-sizing: border-box` |
| 长英文 | `overflow-wrap: anywhere`，不要靠横向滚动看整句 |
| 词块注解 | 短语块允许换行；不要 `inline-flex` 无行撑出屏外 |
| 按钮行 | 操作条用换行或 2 列网格，不要 `nowrap` 一长条 |
| 验收 | 375px / 390px 宽下左右轻扫，页面不跟手横移 |

## 不要做

- 不要为了「功能完整」把 L3/L4 全部钉在首屏。
- 不要一屏两颗渐变主按钮。
- 不要词级三层注解默认全开。
- 不要顶栏复刻桌面胶囊导航。
- 不要用缩小字号、减小热区来塞更多按钮（热区仍 ≥ 44px，优先 48px）。
- 不要新增第四种练法 Tab 却不删旧入口。
- 不要出现整页左右滑动；内容过宽要换行或收进「更多」，不要横向拖。
