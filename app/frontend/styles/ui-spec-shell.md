# Linglish 应用壳层规范（参照 YouTube）

颜色、字体仍以 `tokens.css` / `ui-spec.md` 为准。  
练习页收纳规则见 `ui-spec-mobile-practice.md`。  
**本文件只管：顶栏、侧栏、底栏——把功能收进去，不删功能。**

对照：YouTube 桌面「☰ + Logo | 搜索 | 右侧图标」+ 左侧导航；手机「Logo | 搜索」+ 分类胶囊 + 底栏。

---

## 一句话

顶栏只留品牌、当前任务、账号。  
其余入口进左侧栏（电脑）或底栏 /「更多」（手机）。  
一屏可见一级入口：电脑侧栏约 6–8 项；手机底栏 ≤ 5 项。

---

## 电脑（宽 ≥ 1024）

```
┌──────┬────────────────────────────────────────────┐
│ ☰    │  Logo          （中可搜）     等级 · 账号   │  顶栏 56px
├──────┼────────────────────────────────────────────┤
│ 侧栏 │                                              │
│ 首页 │                 主内容区                      │
│ 训练 │                                              │
│ …    │                                              │
└──────┴────────────────────────────────────────────┘
```

| 区域 | 放什么 | 不放什么 |
| --- | --- | --- |
| 顶栏左 | ☰ 开合侧栏、Logo | 一排文字胶囊 |
| 顶栏中 | 可选搜索；学习页可放「视频 / AI / 实战」3 个分段 | 超过 3 个同级 Tab |
| 顶栏右 | 最多 3 个图标：主操作（如视频库）、通知/安装、账号头像菜单 | 退出、等级全文、安装长按钮并排 |
| 侧栏 | 一级去向 + 工具折叠组 | 播放控制、字幕操作 |

侧栏默认展开宽约 220px；可收成 72px 图标轨（像 YouTube mini）。  
账号菜单收：等级、SVIP、用户名、退出、安装到桌面。

---

## 手机（宽 ≤ 767）

```
┌─────────────────────────┐
│ Logo              🔍 我 │  顶栏 56px + 安全区
├─────────────────────────┤
│ [分类胶囊横滑…]          │  可选，一行
├─────────────────────────┤
│                         │
│        主内容           │
│                         │
├─────────────────────────┤
│ 首页  训练  词汇  我的   │  底栏 56px + 安全区
└─────────────────────────┘
```

| 区域 | 规则 |
| --- | --- |
| 顶栏 | 左品牌或返回；右 ≤ 2 图标（搜索/库、账号）。不要浮动胶囊长条 |
| 分类条 | 横滑 pill，右侧渐隐；只切换同页模式，不跳全站 |
| 底栏 | ≤ 5 项；选中主色 `#0f766e`；专注播放可隐藏 |
| 更多 | 侧滑抽屉或底滑菜单，收纳上传、反馈、主题、语言等 |

禁止整页左右滑；局部分类条可横滑。

## 入口搬迁表（保持功能）

### 首页 `index-desktop.html`

| 现顶栏 | 新位置 |
| --- | --- |
| 今日训练 / 工作台 / 功能 | 侧栏（手机：底栏「训练」+ 抽屉） |
| 学习等级 | 账号菜单 |
| SVIP / 用户名 / 退出 | 账号菜单 |
| 安装到桌面 | 账号菜单或侧栏底部 |
| 登录 / 开始今日训练（游客） | 顶栏右保留一颗主按钮 |

### 视频学习 `video-reader-desktop.html`

| 现顶栏 | 新位置 |
| --- | --- |
| 视频学习 / AI陪练 / 实战场 | 顶栏中分段（≤3）或分类胶囊 |
| 视频库 | 顶栏右主操作图标/按钮 |
| 频道库、播客、网络/本地上传、反馈、词汇 | 侧栏「工具」组 |
| 主题、语言、VIP、返回、首页 | 侧栏或账号菜单 |
| 今日目标 | 侧栏顶部或顶栏次要一行字 |

播放、上一句、语速等**留在播放区**，不进壳层。

---

## 视觉

- 顶栏、侧栏、底栏：白底 `#ffffff`，底/侧分隔线 `#e2e8f0`
- 选中：字色/图标 `#0f766e`；侧栏选中可浅底 `#f0fdfa`
- 图标 24px，描边，`icons.js`
- 触控热区 ≥ 48px（手机）
- 不要把桌面 Speak 胶囊导航原样塞进手机
