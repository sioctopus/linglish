# Linglish 手机与平板界面规范

桌面外观以 `ui-spec.md` 为准。这一份只规定窄屏和触控：安卓手机、iPhone、iPad。
颜色、字体、图标不另起一套。色值仍以 `tokens.css` 和 `ui-spec.md` 为准。

这是网页适配，不是原生 App。用同一套 HTML，靠断点、安全区和触控尺寸区分设备。

日常用语、跟读、精读入口等**练习页**还要满足 `ui-spec-mobile-practice.md`：功能可以齐全，但首屏只露出当前任务需要的一层。  
全站顶栏过挤时，按 `ui-spec-shell.md` 收成 YouTube 式「顶栏 + 侧栏 / 底栏」，入口只搬家不删除。

## 一句话

颜色和胶囊按钮保持桌面那套青绿。手机改成「顶栏 + 底栏 + 单列」；iPad 横屏再放开成侧栏和双列。手指点得到的东西至少 48px，文字不要小于 12px，输入框不要小于 16px。

## 断点

按视口宽度分，不按机型字符串分。

| 档 | 宽度 | 典型设备 | 布局 |
| --- | --- | --- | --- |
| 小手机 | ≤ 375px | iPhone SE、小屏安卓 | 单列，页边 16px，营销大标题降到 28px |
| 手机 | 376–767px | 常见安卓、iPhone | 单列，页边 20px，底部导航 |
| 平板竖屏 | 768–1023px | iPad mini / Air / Pro 11 竖持 | 仍用底部导航，内容最宽 720px 居中 |
| 平板横屏 | ≥ 1024px | iPad 横持、iPad Pro 12.9 | 左侧图标栏，可双列；不再显示底部导航 |

平板横屏不要把桌面胶囊导航原样缩小贴在顶上。桌面胶囊只在宽屏营销页使用。

## 安全区

刘海、灵动岛、底部横条、安卓挖孔和手势条都用 `env(safe-area-inset-*)`，不要写死某一款机型的像素。

页面需要：

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
```

| 位置 | 做法 |
| --- | --- |
| 顶栏 | 内容高 56px，再加 `padding-top: env(safe-area-inset-top)`。总高用 `calc(56px + env(safe-area-inset-top))` |
| 底栏 | 内容高 56px（图标 + 文字），再加 `padding-bottom: env(safe-area-inset-bottom)` |
| 页面底部 | 可滚动内容的 `padding-bottom` 至少是底栏总高，避免最后一行被挡住 |
| 横屏刘海 | 左右也加 `env(safe-area-inset-left/right)`，全屏视频和专注模式尤其要加 |
| 固定按钮 | 悬浮按钮落在底栏之上：`bottom: calc(56px + env(safe-area-inset-bottom) + 16px)` |

高度用 `dvh` / `svh`，不要用 `100vh` 当整屏。iOS 地址栏收起时 `100vh` 会把底栏顶出屏幕。

现有样式里的 `--header-height: 60px`、`--bottom-nav-height: 70px` 是含内边距的旧值。新页面按上表的 56px 内容高加安全区；改旧页面时不要让内容和安全区叠在一起。

## 颜色

与桌面相同，不因设备改色。

| 角色 | 色值 | 手机上用在哪 |
| --- | --- | --- |
| 页面底 | `#f8fafc` | 默认底 |
| 顶栏 / 底栏 / 卡片 | `#ffffff` | 顶栏、底栏、白卡片 |
| 标题 | `#0f172a` | 标题和正文 |
| 说明 | `#64748b` | 辅助说明、未选中的底栏文字 |
| 主色 | `#0f766e` / `#0d9488` | 选中态、强调、推荐边 |
| 薄荷 | `#2dd4bf` | 主按钮渐变的亮端 |
| 天蓝 | `#0ea5e9` | 链接和信息 |
| 主按钮 | `#0d9488` → `#2dd4bf` | 白字，全圆角 |
| 浅底 | `#f0fdfa` / `#ccfbf1` | 功能块、推荐 |

状态色只用于对错和警告。底栏选中用主色，不要给每个 Tab 一种颜色。

## 文字

字体与桌面相同：Manrope，中文回落苹方、微软雅黑、Roboto。不要引入 Axiforma。

| 层级 | 小手机 ≤375 | 手机 | 平板竖屏 | 平板横屏 | 字重 | 行高 |
| --- | --- | --- | --- | --- | --- | --- |
| 营销大标题 | 28px | 32px | 40px | 48px | 400 | 1.15 |
| 区块标题 | 22px | 24px | 28px | 32px | 600 | 1.25 |
| 产品页标题 | 22px | 22px | 26px | 28px | 600 | 1.3 |
| 卡片说明 | 16px | 16px | 18px | 18px | 400 | 1.5 |
| 副文案 | 14px | 14px | 15px | 16px | 400 | 1.5 |
| 界面字 | 14px | 14px | 14px | 14px | 500 | 1.4 |
| 底栏标签 | 11px | 11px | 12px | — | 500 | 1.2 |
| 注释 | 12px | 12px | 12px | 12px | 400 | 1.4 |

界面字最小 12px。输入框、搜索框、文本域至少 16px，避免 iOS 聚焦时自动放大页面。

营销大标题可以在中文之间加少量空格。产品页标题不要拆字。副文案在手机上占满内容宽，不要再套桌面的 480px / 640px 居中限宽；平板竖屏内容容器最宽 720px，横屏主栏最宽 940px，与桌面产品页一致。

## 触控

| 规则 | 尺寸 |
| --- | --- |
| 主按钮、列表行、底栏项 | 高至少 48px，宽至少 48px |
| 图标按钮绝对下限 | 44×44px，优先做成 48×48px |
| 相邻可点区域 | 间隔至少 8px |
| 主按钮（页内） | 高 48px，左右内边距 20px，全圆角 |
| 顶栏图标按钮 | 48×48px 点按热区，图标本身 24px |
| 表单行 | 高 48px，圆角 12px |

悬停不能作为唯一反馈。可点元素用 `:active` 给浅底按压，颜色 `#f1f5f9` 或主色 8% 透明。不要用 3D 厚边。

一屏只有一颗主按钮。次要动作用白底细边框或文字按钮。

## 形状和间距

| 零件 | 手机 | 平板 |
| --- | --- | --- |
| 页边 | 16px（≥390px 用 20px） | 竖屏 24px，横屏 32px |
| 段间距 | 24px；营销页 40–56px | 竖屏 32–40px，横屏 48–64px |
| 白卡片 | 圆角 16px，内边距 16px，阴影 `0 4px 24px rgba(0,0,0,0.04)` | 圆角 20px，内边距 20px |
| 功能浅底 | 圆角 20px，内边距 20px | 圆角 28px，内边距 32px |
| 底部弹层 | 顶圆角 24px，贴底，含安全区 | 宽 ≤ 560px 时改为居中对话框，圆角 24px |
| 列表 | 整行可点，行间用 1px `#e2e8f0`，不要每行一张浮卡 | 同左；宽屏可两列卡片，列距 16px |
| 专注模式 | 四周 16px，再加安全区。播放窗宽 100%，最高 `min(52dvh, calc(100dvh - 280px))` | 四周 24px。横屏播放窗与桌面共用 `--lx-focus-player-max-h`，字幕栏改到下方或右侧 320px |

桌面白卡片的 24px 圆角和 90px 大阴影在手机上过满。手机卡片用上表，不要照搬。

## 导航

### 手机（≤767px）

1. 顶栏固定：左返回或品牌，中标题，右最多两个图标。白底，底边 1px `#e2e8f0`。不要用桌面那条浮动胶囊。
2. 底栏固定：最多 5 项。图标 24px，其下 11px 标签。选中项用 `#0f766e`，未选中用 `#94a3b8`。
3. 当前页只有一项主操作时，主按钮放在内容底部或顶栏右侧，不要和底栏的五项抢层级。
4. 专注播放、全屏视频时隐藏底栏，顶栏可收成半透明。退出控件仍要留在安全区内。

### 平板竖屏（768–1023px）

结构与手机相同。内容列居中，最宽 720px，两侧留出页面底色。底栏可以横贯全宽，五项仍平均分布，不要拉得无限宽：每项最大约 120px，整组居中。

### 平板横屏（≥1024px）

1. 去掉底栏。左侧一条白底图标栏，宽 80px，图标 24px，选中项左侧 3px 主色条。
2. 顶上不再放桌面胶囊。需要标题时用普通顶栏，高 56px。
3. 主栏最宽 940px。练习、视频、字幕可以左右分栏，间距 16px。
4. 营销页在这个宽度直接走 `ui-spec.md` 的桌面排版。

## 页面怎么排

1. 手机首屏：标题、一句灰色说明、一颗渐变主按钮，上下叠放。吉祥物放在标题上方或按钮下方，不要跟标题并排把字挤到两行以下仍不可读。
2. 产品页单列往下排。方案、今天、练习的段间距用 24px，不要用营销页的大留白。
3. 筛选和分段控件横滑，不要挤成两行小字。横滑区右侧渐隐，提示还能滑。
4. 价格、表单、推荐用白卡片。价格数字用 `#0f172a`。浅底上禁止白字。
5. 弹层从底部升起。标题下可有一句说明，主按钮贴在弹层底部并避开安全区。点遮罩或下拉可关闭。
6. 表单标签在输入框上方，不要左右并排。错误文案放在字段下面，用错误红，字号 12–14px。
7. 深色只留给视频画面。顶栏、底栏、页脚、推荐卡保持浅色。

## 图标

与桌面同一套：`js/icons.js`、`styles/icons.css`，描边 SVG，`currentColor`。

| 位置 | 尺寸 |
| --- | --- |
| 顶栏、底栏、侧栏 | 24px |
| 列表行内 | 20px |
| 空状态 | 48px，颜色 `#94a3b8` |
| 主按钮内 | 20px，与白字同色 |

底栏不要用 emoji。庆祝和成就可以保留 emoji。品牌登录图标单独保留。

## 平台差异

三端共用上面的尺寸。下面只处理网页在各系统里表现不同的地方。

| 问题 | 安卓 | iOS | iPad |
| --- | --- | --- | --- |
| 状态栏 / 挖孔 | 顶栏加安全区，不要把标题画进状态栏 | 同样加安全区，盖住灵动岛和刘海 | 竖屏顶距通常更小，仍用 `env()`，不要写死 0 |
| 底部手势条 | 手势导航和三键导航都吃 `safe-area-inset-bottom` | 首页指示条同一变量 | 新款 iPad 同样有底部横条 |
| 点击放大 | 输入框 ≥16px | 输入框小于 16px 会缩放整页，必须 ≥16px | 同 iOS |
| 滚动 | 列表用原生滚动，不要自己拦截触摸 | 横向条加 `-webkit-overflow-scrolling: touch`；禁止整页橡皮筋把固定栏拖走 | 横屏分栏各自滚动，不要整页一起滚 |
| 点击延迟与高亮 | 可点元素 `-webkit-tap-highlight-color: transparent`，用 `:active` 代替 | 同左 | 键鼠指针时可以加 hover，手指路径仍要有 `:active` |
| 地址栏 | Chrome 收起地址栏会改变可视高度，用 `dvh` | Safari 同理，固定底栏用 `position: fixed` 加安全区 | 分屏时宽度会掉进「手机」或「竖屏」档，允许布局跟着变 |

安卓和 iOS 不分别做两套颜色或两套组件。差别只处理安全区、输入字号和滚动。

## Mac 和优画平板

Mac 不单独做一套皮肤。窗口宽度落到哪一档，就用哪一档布局：窄窗口用手机规则，768–1023 用平板竖屏，1024 以上且是鼠标或触控板（`hover: hover` 且 `pointer: fine`）用 `ui-spec.md` 的桌面胶囊。字用系统抗锯齿，安全区仍走 `env()`，避免刘海 Mac 把顶栏吃掉。

优画平板按安卓平板处理，不看机型名字。竖屏（宽 768–1023）用底部导航，内容最宽 720px。横屏（宽 ≥1024，且是手指）去掉底栏，主栏最宽 940px，走宽屏学习页。iPad 同样。iPadOS 浏览器会自称 Mac，要同时看 `maxTouchPoints > 1`，不能只看 User-Agent。

页面由 `styles/device-adapt.css` 和 `js/device-adapt.js` 落地。静态 HTML 在输出时自动带上这两份文件。视频学习页在手机和平板竖屏打开移动阅读器，横屏平板和 Mac 打开桌面阅读器。

## 视口

手机和平板竖屏：**页面不能左右滑出屏幕。** 只允许上下滚动。

- `html, body`：`max-width: 100%; overflow-x: hidden; overscroll-behavior-x: none`
- 主内容容器：`min-width: 0; max-width: 100%; box-sizing: border-box`
- 长句、标签、按钮行：换行或收纳，不要靠横向滚动才能看全
- 刻意横滑的筛选条可以局部 `overflow-x: auto`，但不得带动整页横移

练习页细则见 `ui-spec-mobile-practice.md`。

## 不要做

- 不要把桌面 64px 标题、160px 段距、24px 大圆角卡片直接放进手机。
- 不要用 `100vh` 锁死整屏，不要忽略安全区。
- 不要让可点区域小于 44px，不要只做 hover、没有按下态。
- 不要在底栏放超过 5 项，不要一屏两颗主按钮。
- 不要给 Tab 分色，不要把主按钮改成纯蓝或 3D 厚边。
- 不要白字放在白底、浅灰底、浅青底上。
- 不要在产品控件上用 emoji 或 `▶` 当图标。
- 不要为安卓和 iOS 各写一套主题色。
- 不要整页左右滑动；内容过宽要换行或收纳。

改手机或平板页面时，颜色以 `tokens.css` 为准，图标以 `icons.js` 为准，尺寸以本文件为准。宽屏营销页仍以 `ui-spec.md` 为准。
